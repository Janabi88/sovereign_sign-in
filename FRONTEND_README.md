# Coherence Vault — Frontend (MVP)
- Connects to Superhero Wallet (Testnet)
- Paste your ct_ address
- Submit a record (hash/CIDs/metrics)
- Read back by id and show get_next_id

## Env
Copy .env.example to .env and set:
- VITE_CONTRACT_ADDR=ct_...
- VITE_NODE_URL=https://testnet.aeternity.io
- VITE_COMPILER_URL=https://v8.compiler.aepps.com

## Dev
npm run dev
